# Конфликт в Git

## Где возник
В файле README.md, строка "## Статус".

## Причина
В ветке main было значение "в разработке",
в ветке feature/conflict-demo — "MVP готов".
Обе ветки меняли одну и ту же строку.

## Как исправлен
Вручную оставлено "MVP готов",
маркеры конфликта (<<<<<<<, =======, >>>>>>>) удалены,
сделан отдельный коммит:
"fix: разрешить конфликт статуса в README".
